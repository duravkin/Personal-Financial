# Personal-Financial

Для запуска приложения можно воспользоваться быстрой командой из корня репозитория (с правами sudo пользователя):
```
docker compose up --build
```

Приложение будет доступно по адресу: http://localhost:3000

Используемый стек:
- Golang + Gin
- Solid.JS
- PostgreSQL
